# IS 475 (Sprint 1)

SkillBridge is a web-based platform that connects students and employers through a streamlined and interactive system. Students create detailed profiles that highlight their skills, interests, education, and career goals, allowing them to present themselves effectively to potential employers. Employers use the platform to post short-term projects, internships, and opportunities that match specific skill sets and requirements. The system enables both parties to communicate directly, helping them align expectations and find suitable matches through filtering tools and tag-based search functionality. SkillBridge is built with a responsive web front-end that provides an intuitive user experience, while backend services manage data processing, authentication, and communication between users. A centralized database securely stores user profiles, project listings, and application data, ensuring efficient retrieval and management of information. Overall, SkillBridge supports meaningful connections, encourages practical experience for students, and helps employers discover qualified candidates in a structured and efficient environment.

## Getting Started

Run the main script:

```bash
python main.py
```
